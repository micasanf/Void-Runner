# 🚀 Void Runner — Local Game Server

A high-performance space survival game server built with **Go**.

## 🌌 About
Void Runner is a browser-based survival game hosted by a custom Go backend. The server not only serves the game assets but also automatically discovers your local network IP, allowing you to host game sessions for other devices on your Wi-Fi.

## 🛠️ Built With
*   **Go (Golang):** High-concurrency web server and network discovery.
*   **HTML5/CSS3:** Retro-futuristic HUD and UI.
*   **JavaScript:** High-performance canvas-based game engine.

## 🚀 Getting Started

### Prerequisites
*   [Go](https://go.dev/dl/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Void-Runner.git
   cd Void-Runner
   ```

2. Run the server:
   ```bash
   go run main.go
   ```

3. Open your browser and navigate to:
   *   Local: `http://localhost:8080`
   *   Network: Check the terminal for your local IP!

## 🎮 How to Play
*   **W/A/S/D or Arrows:** Navigate your ship.
*   **SPACE:** Activate Thruster (Boost).
*   **Objective:** Survive as long as possible in the void. Avoid asteroids and advance through sectors!
